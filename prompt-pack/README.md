# Prompt pack

Each file here is a prompt. Open your AI assistant (Claude, or any coding
assistant), paste the prompt, then paste the contents of
`outputs/dataflow.json` (and `outputs/security.json` where the prompt says so).
Save the output at the path named at the top of the prompt.

Rules the pack follows:
- Every claim must cite evidence from the scan (file and line) or be marked
  `[assumption - verify]`.
- The AI output is a draft. You are the data owner; you review and decide.
- These documents are a privacy program skeleton, not legal advice.
