# Prompt 6: Evidence-based privacy notice draft  → save as privacy/06-privacy-notice-draft.md

From the Bearer dataflow JSON below, draft a plain-language privacy notice
that claims ONLY what the scan shows the code actually does: what's collected,
where stored, which third parties receive what and why. Use layered format:
short summary up top, details below. Insert [COMPANY], [CONTACT EMAIL],
[STATE] placeholders. Add a "Review before publishing" list naming every
claim that needs human confirmation (retention periods, rights processes,
anything the scan can't see). This is a draft for counsel, not final.
